# Aturan

1. Tugas kita ingin menambahkan fitur baru ke proyek ini.
2. Harus mengikuti prinsip yang ada di bawah.
3. Harus mencari datanya di web dengan menggunakan `websearch`.
4. Perbarui file `rencana_fitur_baru.md` dan susun berdasarkan tingkat prioritasnya, terendah dulu, lalu susun agar mudah dibaca pengguna.
5. Dilarang merubah kode `.dart`.
6. Semua yang ditambahkan harus dari referensi aplikasi lain.
7. Sertakan link APK referensinya di dalam fitur baru ini.

- Di APK mereka ada fitur apa saja.
