# Aturan

jangan berasumsi liar

1. Baca terlebih dahulu file AGENTS.nd lalu patuhi aturannya.
2. kerjakan 5 task di file task.md. dimulai dari bug runtime dan yang paling tinggi dulu tingaktanya baru kebawah.
3. hanya kerjakan task yang statusnya `implementasikan` saja selain itu jangan kerjakan harus laporan dulu kesaya.
4. setelah mengerjakan satu task wajib edit dulu file task.md nya agar menandai task itu dengan selesai atau dilewati.
5. jangan mengerjakan task yang file nya sedang terbuka di editor dan tandai task nya dilewati saja.
6. untuk task yang ternyata setelah di analyze error nya tak kunjung hilang maka stop dan rollback isi file .dart nya ke semula lalu tandai task nya sebagai dilewati.
7. untuk task yang ternyata sudah diimplementasikan` tandai dengan selesai.
8. satu task satu tugas, misal nya mengerjakan task pertama dan ternyata task nya sudah `diimplementasikan` berarti tertanda 1/5, jika task nya ternyata lint error nya tak kunjung hilang setelah 3 kali perbaikan dan stop lalu tandai task nya sebagai dilewati berarti tertanda 2/5, jika task yang ternyata file dart nya sedang terbuka di editor berarti stop dan tandai sebagai dilewati task nya berarti tertanda 3/5, jika task sudah selesai di implementasikan berarti tertanda 4/5,
9. jika sudah mengecek 5 task stop dulu jangan lanjut tunggu perintah saya untuk melanjut kan ke 5 task selanjut nya lagi.
10. setiap ingin mengedit file tolong buat file backupnya dulu di folder .backup task dan kasih tipe .bak contoh app.dart.bak.
11. komentar : tambahkan komentar ke kode yang diedit/ditambahkan jelaskan alasannya kenapa diedit/ditambah. harus deskriptif dan tidak panjang juga.
12. lewati : setiap status lewati beri penjelasan kenapa sebuah task dilewati
13. flutter analyze : setelah itu jalankan flutter analyze harus bersih dari linter.
