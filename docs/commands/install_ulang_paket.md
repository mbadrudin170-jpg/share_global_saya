# Install Ulang Paket

## Tujuan
Menginstal ulang semua paket yang ada di `pubspec.yaml` satu per satu.

## Langkah Kerja
1. Instal ulang semua paket yang ada di `pubspec.yaml` satu persatu dengan menjalankan `flutter pub add`.
2. Setelah semua terinstal, susun paket sesuai abjad.

## Larangan
- Jangan menulis langsung di `pubspec.yaml`.

## Ketentuan
- Gunakan `flutter pub add` untuk setiap paket.
